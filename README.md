# CareQueue

CareQueue is a friendly concept for an AI chat and voice care companion. This repository currently contains a responsive, glassmorphic front-end demo.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. There are no build tools or package dependencies.

## What’s in the demo

- Responsive landing page and glass-effect interface
- Interactive chat with local, preset demo responses (not connected to an AI service)
- Browser speech recognition for voice input where supported, plus spoken replies
- Medical safety messaging and emergency guidance

Microphone access may require a secure context such as `https://localhost` or a deployed HTTPS site. Browser voice recognition and speech output depend on browser support and permissions.

## Important

CareQueue is a website demo, not a medical device or healthcare service. It does not diagnose, treat, or provide individualized medical advice. Do not enter sensitive personal health information. For care, contact a qualified healthcare professional; in an emergency, call your local emergency number.
